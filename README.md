## 📌 Overview
**HireQuest** is an AI-driven Virtual Reality (VR) job interview simulation platform designed to help candidates practice and improve their interview skills in a realistic, immersive environment.

The system leverages Large Language Models (LLMs) to generate dynamic, role-specific interview questions, evaluate candidate responses in real-time, and provide structured, actionable feedback.

---

## ✨ Key Features
- **Dynamic Question Generation:** Uses fine-tuned/prompt-engineered LLMs to adapt questions based on candidate performance and targeted job roles.
- **FastAPI Backend:** High-performance RESTful API endpoints managing the interaction between the VR client and the LLM engine.
- **Automated Feedback & Scoring:** Analyzes candidate responses and evaluates clarity, relevance, and technical accuracy.
- **Hugging Face Integration:** API backend hosted directly on Hugging Face Spaces for scalable deployment.

---

## 🛠️ Tech Stack
- **AI/LLM Engine:** Python, Hugging Face Transformers, PyTorch, Prompt Engineering / Fine-Tuning.
- **Backend API:** FastAPI, Uvicorn, Pydantic, Docker.
- **Environments & Tools:** Git, Hugging Face Spaces.
